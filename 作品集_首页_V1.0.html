问需 · 装修需求采集与解读系统

给装修公司的工具：房主填需求单 → 设计师出门前拿到一份沟通清单 → 现场照着问、带一份记录回来

  • 三端已上线
  • 3 位设计师访谈
  • 规则与 AI 的分工
  • 数据外发脱敏
  • 按实测验收
  • 三个端都已上线：房主端（小程序 / H5）、设计师端（桌面端）、现场端（离线可用）
  • 需求来源：3 场设计师访谈产出的必问口径和「遗漏台账 5 类」，优先级按访谈结果排，不按自己的感觉排
  • 人机分工：模型只用在解读端推导还要核实什么，采集端一行都不调；清单每条都标了来源（规则托底 / 你来定 / 模型推导）
  • 数据边界：住址、电话这些字段离开内网前按策略替换，外发留审计

直聘打招呼助手

给求职者的工具：粘贴一段 JD，用已存的简历生成 3 条可直接发送的打招呼话术，以及逐条可采纳的简历改写建议

  • 需求来自自己
  • 一条硬规则
  • 先建评测再调提示词
  • 数据不外传
  • 已上线运行：从粘贴 JD 到拿到 3 条话术，线上实测 2.9 秒；一次生成成本约 0.0038 元
  • 一条硬规则：写出来的经历、技能和数字必须能在简历原文里找到出处，找不到就算失败
  • 人评 8 组真实输出：敢直接发 3.75 / 5、无夸大 3.63 / 5；像不像真人写的只有 3.00，这是下一版要补的

跨境电商 AI 广告素材生成系统

面向跨境电商卖家的广告素材工作台：从商品分析到合规检查一共六段，每段由一个独立的 Agent 负责，输出一份能直接拿去做的创意方案

  • 六段工作流
  • 人机分工
  • 合规独立复核
  • 边界如实
  • 可运行 MVP：主 Agent 带 6 个专业 Agent 走，每段先定清输入和输出，不用担心中间对不上
  • 真实链路跑通过一次：便携咖啡机 / 美国 / Meta，输入输出样例已保存
  • 没做到的：图片生成还是占位图，也没做用户访谈，这两项没有写成已完成
