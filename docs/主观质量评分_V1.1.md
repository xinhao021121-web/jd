## 一、为什么机器评测之外还要人评

现有评测全是**机器可判定**的规则：数字与技能能否溯源、套话黑名单、长度区间、锁定区块。它们能回答「有没有违规」，回答不了三件事：

1. **像不像真人写的**——规则判不了语气，黑名单只能拦住已知的套话；
2. **敢不敢直接发出去**——这是用户的真实决策点，只有人能给答案；
3. **有没有夸大**——规则只能查「简历里有没有这个数字」，查不出「语气上是不是把参与说成了主导」。

所以这三项交给人评，与机器评测是分工关系：**机器守住底线（合规、溯源、长度），人判断质量（像不像、敢不敢发）。**

## 二、三个维度与 1–5 的判据

评分对象：每组样本生成的 **3 条话术作为一个整体**（用户发送时是从 3 条里挑 1 条，不是逐条发）。

### A. 像不像真人写的

| 分 | 判据 |
|----|------|
| 1 | 明显机器腔，套话成串（「贵公司岗位非常感兴趣」式） |
| 2 | 能读，但句式模板化，读两行就出戏 |
| 3 | 基本像人写的，个别措辞生硬 |
| 4 | 像同行随口写的一段，读不出机器痕迹 |
| 5 | 完全像本人手写，带个人语气 |

### B. 敢不敢直接发送

| 分 | 判据 |
|----|------|
| 1 | 不敢发，会立刻改 |
| 2 | 要大改才敢发 |
| 3 | 改一两处就敢发 |
| 4 | 基本可直接发，顶多微调标点 |
| 5 | 一个字不改直接发 |

### C. 无夸大（越界风险越低分越高）

| 分 | 判据 |
|----|------|
| 1 | 明显夸大：写了简历里没有的经历或数字 |
| 2 | 有夸张表达，容易被追问 |
| 3 | 基本贴合简历，个别地方拔高 |
| 4 | 与简历一致，措辞克制 |
| 5 | 完全经得起追问，逐句都能在简历里找到依据 |

## 三、评分流程

1. 打开 `reports/主观评分_样本输出.md`（8 组样本 × 3 条话术，2026/09/21 由线上真实模型生成）；
2. 对每组样本，按上面三个维度各打一个 1–5 分；
3. 把 24 个分填进第四节的表；
4. 汇总时同时给出**每个维度的均分**与**三项总均分**，并指出得分最低的样本——低分样本比均分更有用，它指向下一次要改什么。

**注意**：评分时不要回看质量回归报告里的机器结论，否则会被人评之外的信息污染。

## 五、评分结果与结论

| 维度 | 均分 | 落在哪一档 |
|------|------|-----------|
| A 像真人写的 | **3.00** | 「基本像人写的，个别措辞生硬」 |
| B 敢直接发 | **3.75** | 「改一两处就敢发」与「基本可直接发」之间，偏后者 |
| C 无夸大 | **3.63** | 介于「与简历一致，措辞克制」与「个别地方拔高」之间 |
| **三项总均分** | **3.46 / 5** | — |

| 指标 | 数值 |
|------|------|
| 样本数 | 8；评分数 24 |
| 最高样本 | S1 / S3 / S4 / S7（各 11 分） |
| 最低分样本 | **S8 · 平面设计（9 分）** |
| 最低单元格 | **S8 的 A = 2**（「句式模板化，读两行就出戏」） |

**三条观察**：

1. **三个维度不是齐平的，短板很明确：A 只有 3.00，比 B（3.75）低 0.75。** 也就是说，这些话术「安全、发了不会出事，但还不够像人写的」。而 A 恰好是**机器规则完全测不到的那一维**——机器侧同一批样本的结论是 95.8% 合规率、0 例编造，看起来接近满分。两层测的不是一回事，这就是 N5 的价值。
2. **B 的 3.75 支持产品的核心承诺，但有保留。** 8 组里 6 组给了 4 分（「基本可直接发，顶多微调标点」），2 组给了 3 分（「改一两处就敢发」）。没有人给 5 分——**没有一个样本是「一个字不改直接发」**，所以「复制一条可以直接发送的话术」这个说法要按「基本可直接发、可能需要微调」来讲，不能讲成零修改。
3. **唯一跌破 3 分的样本是平面设计（S8），且跌在 A 上。** 这与其他 7 组集中在本产品目标人群（技术岗与产品岗）之外的场景一致——S8 是产品边界外的样本，低分反而说明目标人群的定位是有意义的。但样本只有 1 组，**不足以据此下结论，只能作为下次归因的入口**。

**由这份结果直接产生的待改进项**（不在此处下结论）：

- 对 A 维度做 bad case 归因：拿 S8 与 A 得 4 分的 S3 对比，看差异出现在句式、信息密度还是第一句的落脚点上；
- 判断「像不像真人写的」能否拆成可执行的提示词约束（例如句式必须变化、第一句直接给匹配点），改完用**同一套判据、同一批样本**重测——同一套判据才看得出改动是否有效。

两点必须写清楚，否则这版数字会被高估：

1. **两版的量法不同**（一个是每组一个数、一个是三维度各一个数），所以 2.13 与 3.46 **不是同一个测量两次得到的结果**，不能直接说「重测后提高了」；
2. **评分者就是产品作者，且经历了「先给低分、后重做」的过程。** 自行评分本身就带自证倾向，评分者已知第一版结果后重做，这个风险只会更大——这是本文件最大的局限，也是它只能作为「方法演示」而不能当外部证据的根本原因。

## 七、这份评分不能支撑什么

- **样本量**：8 组样本、1 名评分者，任何百分比都谈不上统计意义；
- **评分者偏见**：评分者就是产品作者，存在「希望分数好看」的自证倾向，且如上所述经历过一次重做——这一条必须写进报告，不能省；
- **算不出一致率**：评分者一致率需要 ≥2 名评分者，单人评分没有这个数，因此**不能**声称「评分稳定」；
- **不是外部证据**：它替代不了外部盲测；[公开讨论材料_V1.0.md](公开讨论材料_V1.0.md) 里的「不得写成访谈」同理，这里**不得写成「用户调研」或「用户满意度」**。

**引用时必须带上的那句局限**（照抄即可）：

> 这是作者本人对 8 组样本的主观评分（三维度各 1–5 分），属于方法演示：评分者即产品作者、样本 8 组、无第二名评分者因而不存在一致率，不能代表用户评价。
