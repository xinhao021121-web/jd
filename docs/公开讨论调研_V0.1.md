## 一、我能做到哪一步（实测，不猜）

我实际尝试过以下渠道，结论是**这份调研的主体必须由你在浏览器里完成**：

| 渠道 | 命令行可访问 | 实测结果 |
|------|------------|---------|
| 知乎 | 否 | HTTP 403 |
| 小红书 | 否 | 内容由 JS 渲染，抓到的 HTML 里没有笔记正文 |
| 牛客网 | 否 | 讨论列表由 JS 渲染，HTML 里只有导航文本 |
| 百度贴吧 | 否 | HTTP 403 |
| V2EX | **可以** | 有公开 API，能取到标题与正文；但内容是技术圈的「职场话题」 |
| 浏览器自动化 | 不可用 | 运行环境缺授权（`Codex auth token is unavailable`），无法代你操作浏览器 |

所以本文的定位是：**给你一份可以直接照着做的检索方案**，并附上我实际抓到的样本作为方法示范。内容是真实的，不是编的；但样本量与相关性都有限，这一点我在下面写清楚了。

## 二、我实际抓到的样本（V2EX · 职场话题节点）

检索时间：2026/09/21；方式：`GET /api/topics/show.json?node_name=career`（公开 API，无需登录）。

**样本 1** · 标题《最近后端的工作给我找麻了》· [1243593](https://www.v2ex.com/t/1243593)

> 「以前想着不行还能去外包兜底,结果现在外包的竞争也这么大嘛?就两个岗位来了几十个人,五个人一组进去群面...刷了一下 BOSS,感觉正经还在招人的就剩几个外包了,有同感的吗?」

**同批次的标题**（仅有标题，未取正文）：「岗位推进都有大半个月了，对面是不是鸽了？」「远程岗位是靠谱的吗？」「我感觉不想再做开发了」。

**这批样本说明什么，不说明什么**：

- 说明：V2EX 上确实有真实的求职情绪与 BOSS 使用体验，抓取方式可行；
- 不说明：它与本产品的核心痛点（打招呼话术、按 JD 改简历）**相关性弱**——这里讨论的是「岗位变少、竞争加剧」，不是「这段话该怎么写」；
- 结论：**V2EX 不解决问题**。内容富矿在小红书与牛客，而这两个渠道我抓不到。

## 三、检索清单（你在浏览器里做）

按优先级排序，做完第一项就已经够用了：

| 优先级 | 平台 | 去哪找 | 关键词 |
|-------|------|-------|--------|
| 1 | **牛客网** | 讨论区 / 求职板块 / 面经 | 投了没人回、打招呼、已读不回、简历被筛、海投 |
| 2 | **小红书** | 搜索页 + 话题标签 | 求职、已读不回、打招呼话术、简历优化、投递记录 |
| 3 | 知乎 | 问题与回答 | 为什么投简历没人回、BOSS 打招呼、AI 改简历 |
| 4 | V2EX | 职场话题、酷工作节点 | 找工作、投简历、BOSS |

**筛选标准**（不满足就跳过，避免把噪音当证据）：

1. 时间在近 12 个月内——招聘市场变化快，两年前的体验不能代表现在；
2. 帖子里有**具体行为或数字**（「投了 80 个」「写一条要几分钟」），而不是纯情绪宣泄；
3. 发布者属于互联网技术岗或产品岗求职者优先；其他岗位的记录也可以，但要单独标注；
4. **每个待验证假设收集 5 条以上**，不够就说明该假设暂时没有公开材料支撑。

## 五、引用规范（这几条不能破）

1. **措辞**：作品集里只能写「公开讨论材料」，不能写「访谈」或「调研了 N 位用户」；
2. **标注**：每处引用都要带平台与检索时间，例如「（牛客网，2026/09）」，并写明样本条数；
3. **匿名化**：不写用户名、昵称、头像等可识别信息；
4. **不整段复制**：只摘最短的必要片段，其余用自己的话概括；
5. **必须写局限**：愿意发帖的人不等于所有人；帖子里看不到「没发帖的那批人」怎么想。这条要写进引用它的那一节，不能只写在附录里。

## 六、材料怎么映射到假设

| 假设 | 找什么关键词 | 找到什么算支持 | 找到什么算反驳 |
|------|------------|--------------|--------------|
| H1 打招呼是重复劳动 | 打招呼、话术、复制 | 有人描述「每次都复制同一段」或「写一条要 X 分钟」 | 有人说「随便发发就行，不在意」 |
| H3 简历按岗位定制率低 | 改简历、一份简历投所有 | 有人明说「懒得改」「改一次太费劲」 | 有人说「每个岗位都认真改」 |
| H4 通用 AI 的弃用原因 | AI 改简历、AI 写打招呼 | 提到套话、编造、要自己调提示词，或「每次要重新说一遍情况」 | 有人表示一直在用且满意 |
| **H7 看不懂 JD / 判断不了岗位** | JD 看不懂、岗位描述、够不够格 | 有人描述「不知道这个要求对应我会不会」 | 很少见——若真找不到，H7 的优先级要下调 |
| H11 数据顾虑分两类 | 简历隐私、信息泄露 | 分别出现「怕被骚扰」与「怕项目/作品被泄露」两类说法 | 普遍表示不在意 |
